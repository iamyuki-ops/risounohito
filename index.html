データ・推計方法

統計出典と調査年
基礎データとして2025年国勢調査の 年齢階級別未婚者数を収録した試作版です。

出典候補： 総務省統計局 「令和7年（2025年）国勢調査」 表4-3-1。

e-Statで統計表を確認

注意：収録値の原表照合は未完了です。 正式な公的集計値として使用する前に 原表との一致を確認する必要があります。

人数の算出方法
年齢5歳階級別の未婚者数を合算しています。

範囲の境界が5歳階級の途中にある場合は、 その階級内に人数が均等に分布すると仮定しています。

性別、国籍、身長、年収、居住地、子ども、 学歴、雇用形態、たばこ、飲酒を組み合わせた 人数推計には、現時点では対応していません。

未対応条件が指定された場合は、 年齢条件だけから求めた上限の目安を表示します。 すべての理想条件を満たす人数ではありません。

プライバシー・免責
条件の計算はブラウザ内で行い、 アプリから入力情報を保存・送信しません。

GitHub Pagesのアクセスログや、 広告リンク先の情報取得は別です。

「未婚」は、結婚歴が一度もない人を指します。

数字は個人の魅力・価値・実際に出会える確率を 示すものではありません。
