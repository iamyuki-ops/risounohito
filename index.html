データ・推計方法

使用データ
年齢別の未婚人口について、 国勢調査の数値として収録した 暫定データを基礎にしています。

出典候補： e-Stat

18〜19歳は15〜19歳階級の 2/5を按分した暫定値です。

基礎人口の原表との最終照合、 および複合条件の係数の統計的検証は 完了していません。

人数の計算方法
年齢階級別の人数に、 選択した条件に該当する割合を 掛け合わせています。

性別・婚姻歴・国籍・都道府県・身長・ 年収・学歴・雇用形態・子ども・喫煙・ 飲酒の割合には、仮定上の係数を含みます。

年齢、性別、雇用形態に応じて 一部の割合は変化しますが、 条件間の相関を完全には再現していません。

表示結果は検証前の試算値です。 正確な該当者数ではありません。

プライバシー・免責
入力した条件と計算結果は、 このページのブラウザ内で処理します。

アプリ独自のプロフィール保存や サーバーへの入力情報送信は行いません。 Xへの投稿はユーザー操作時のみです。

GitHub Pagesのアクセスログ、 楽天広告画像の読み込みやリンク先の通信は別です。

表示人数は、個人の価値や 実際に出会える確率を示しません。
